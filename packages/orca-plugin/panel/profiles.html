Orca–Pi Profiles

Read-only summary of Pi role profiles: effective model/thinking, tool count, skill names/count, extension count, context-file policy, and validation state. The CLI/profile file is authoritative.

No live data in the panel.

Run in a terminal for live diagnostics (read-only):

orca-pi profiles list
orca-pi profile show <name>
orca-pi profile inspect <name> --context-summary
orca-pi profile validate
orca-pi profile path

Conservative actions: validate profiles, show/open/copy config location (orca-pi profile path), refresh/reload configuration (orca-pi profiles list). Editing happens in config files only — the panel keeps no local store.

Targets Orca app 1.4.196 (pluginApi 1). See docs/ORCA_PLUGIN_API.md.
