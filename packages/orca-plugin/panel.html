Orca–Pi Status

Plugin: orca-pi 0.1.0 (pluginApi 1, bridge 1.0.0 / protocol 1)

Structured bridge: live diagnostics via typed requests (bridge.capabilities, diagnostics.doctor, worktree.context). The panel never spawns processes.

Live diagnostics live in the companion CLI (read-only):

orca-pi --version
orca-pi doctor
orca-pi doctor --json
orca-pi profiles list
orca-pi profile validate

Pi role profiles have their own sidebar (Orca–Pi Profiles, panel/profiles.html) backed by orca-pi profile show|inspect|validate|path through the bridge (profiles.list, profile.read, profile.validate, launch.preview).

Targets Orca app 1.4.196+ (Host API v0 re-audited 2026-09-11, commit 9aa0f7e). See docs/ORCA_PLUGIN_API.md.
